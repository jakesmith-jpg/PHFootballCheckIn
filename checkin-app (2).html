🔧 Google Sheets Setup
Step 1: Open Google Sheets, create a new spreadsheet named PHF Attendance. In row 1, add headers: Timestamp | Name | Session | Date | Time
Step 2: In that sheet, click Extensions → Apps Script. Delete any existing code and paste the script below, then click Save (💾).
Step 3: Click Deploy → New deployment. Choose type Web app. Set "Execute as" to Me and "Who has access" to Anyone (even anonymous). Click Deploy, grant permissions when prompted, and copy the /exec Web App URL (not the /dev URL).
Step 4: Paste that URL here and click Save. This app will then log every check-in directly to your sheet!

Apps Script Code:
function doGet(e) { try { var sheet = SpreadsheetApp .getActiveSpreadsheet() .getActiveSheet(); var p = e.parameter; sheet.appendRow([ p.timestamp || new Date().toISOString(), p.name || "Unknown", p.session || "Practice", p.date || "", p.time || "" ]); var output = ContentService .createTextOutput(JSON.stringify({status:"ok"})) .setMimeType(ContentService.MimeType.JSON); return output; } catch(err) { return ContentService .createTextOutput(JSON.stringify({status:"error",msg:err.toString()})) .setMimeType(ContentService.MimeType.JSON); } }
